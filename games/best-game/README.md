# 霓虹风暴 · NEON SURGE

一款**单文件、零依赖**的霓虹风格竞技场生存射击游戏（Geometry Wars × 吸血鬼幸存者）。
全部渲染、玩法、UI、音效与配乐都在 `index.html` 一个文件里——音频由 WebAudio 实时合成，没有任何外部素材。

## 运行

双击 `index.html` 即可游玩；或起一个本地服务器：

```bash
python3 -m http.server 8642
# 打开 http://localhost:8642
```

## 玩法

在封闭竞技场中生存尽可能多的波次。击杀敌人会出现经验水晶，升级时三选一构筑你的火力路线；每 5 波会有**巨像 Boss** 降临（弹幕、冲撞、召唤三阶段）。

| 操作 | 桌面 | 触屏 |
| --- | --- | --- |
| 移动 | `WASD` / 方向键 | 左半屏虚拟摇杆 |
| 瞄准 | 鼠标（不动鼠标则自动索敌） | 右半屏摇杆（松开自动索敌） |
| 射击 | 自动开火 | 自动开火 |
| 冲刺（无敌帧） | `空格` | 右下角 DASH 按钮 |
| 暂停 / 静音 | `P` / `M` | 右上角按钮 |

## 特性

- 6 种敌人 + 多阶段 Boss，波次导演动态控制刷怪强度
- 16 种升级（常规 / 稀有 / 史诗）：多重弹道、穿透、反弹、环刃、追踪导弹、冲刺新星、吸血……
- 连击倍率计分、最高分本地存档（localStorage）
- 当前战局自动保存，可从主菜单继续
- 账号经验支持多局累积，账号等级会提升下一局的船体、火力、移速、拾取范围和经验倍率
- 全套"打击感"：粒子、碎片、冲击波、屏幕震动、命中停顿、慢动作死亡
- WebAudio 合成音效 + 138 BPM 合成波 BGM（随波次叠加配器、Boss 战变调）
- 高分屏适配、移动端双摇杆、标签页切换自动暂停
