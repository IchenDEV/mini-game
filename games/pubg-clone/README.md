# 孤圈行动 LAST CIRCLE — 第三人称大逃杀原型

基于 Three.js + TypeScript + Vite 的浏览器端 battle royale 生存射击原型：
1 名玩家 + 28 名 AI，在一张 800m × 800m 的程序化地图上跳伞、搜刮、交战、随安全区收缩决出最后幸存者。
所有美术资产均为程序化生成的原创低多边形风格，不包含任何第三方 IP 内容。

## 运行

```bash
npm install
npm run dev        # 开发模式（默认 http://localhost:5180）
npm run build      # 类型检查 + 产物构建
npm run preview    # 预览构建产物
```

打开页面 → 点击「进入战场」→ 所有人乘运输机沿航线飞越地图，自选时机跳伞（AI 也会在各自目标点跳出），第一屏即是游戏本体。

| E | 拾取物品 |

## 玩法循环

运输机跳伞 → 搜刮（房屋 / 仓库 / 军备库刷新武器、护甲、药品、配件）→ 装备成长
→ 与 AI 交战（AI 会搜物资、向安全区转移、追击、低血量撤退治疗）
→ 安全区分 7 个阶段收缩，圈外持续掉血 → 第 3 / 5 阶段触发空投（史诗武器 + 三级套）
→ 活到最后即获胜；被淘汰显示排名、击杀、伤害与存活时间。

## 画质升级基线记录（Cinematic Upgrade Phase 0）

升级前（toneMappingExposure 0.88 + 重暗角 0.24 时代）观察到的视觉问题：

| 地图 | 问题 |
| --- | --- |
| 草原（绿野围城） | 白天整体偏暗，草地中间调发灰，屏幕四角被暗角压黑 |
| 雨林（雾林行动） | 树冠下中间调发黑，雾色偏灰绿、天空补光不足，林下几乎看不清轮廓 |
| 沙漠（烈日荒原） | 远景灰蒙、通透感不足，沙面缺少阳光的暖反射 |
| 室内 | 建筑内无补光来源，反差不足，室内物件辨识度低 |

性能基线（M 系列 MacBook · Chrome · 默认窗口）：

- `npm run build`：约 1.8s（tsc + vite），产物 ~700 kB（gzip ~194 kB）。
- 世界生成：进入地图阻塞主线程约 1-3s（雨林 1.3 万棵树最久）。
- 帧率：三张地图地面阶段约 60 FPS；GTAOPass 实测有 50 倍帧时间开销已弃用，AO 采用烘焙接触阴影。

每阶段完成后验证：`npm run build` + `npm run dev`，浏览器进入 `grassland` / `desert` / `jungle` 各一次，确认无黑屏、无材质丢失、无控制台异常。

## 项目结构

```
src/
├── main.ts                入口
├── core/
│   ├── game.ts            游戏状态机与主循环编排
│   ├── ctx.ts             共享上下文类型
│   ├── input.ts           键鼠输入 / 指针锁定
│   ├── camera.ts          第一/第三人称双模相机（碰撞、ADS 变焦、抖动）
│   └── sfx.ts             WebAudio 程序化音效（含引擎/风声/鸟鸣环境音）
├── world/
│   ├── world.ts           程序化地图：地形/河流/桥/城镇/军备库/植被/草丛/小地图烘焙
│   ├── textures.ts        程序化贴图：草地/砖墙/灰泥/波纹钢/屋顶/木板/混凝土/天空
│   ├── plane.ts           开局运输机航线
│   └── colliders.ts       AABB+圆柱碰撞、空间哈希、射线检测
├── entities/
│   ├── character.ts       角色基类：物理、程序化模型、护甲伤害结算
│   ├── player.ts          玩家控制：移动/射击/拾取/治疗/投掷/背包交互
│   └── bot.ts             AI：感知-决策-移动-战斗状态机
├── combat/
│   ├── weapon.ts          武器实例（稀有度/配件/弹匣）
│   └── combat.ts          射击判定、近战、手雷模拟与爆炸
├── items/
│   ├── defs.ts            武器与物品数据表
│   ├── inventory.ts       背包容量与堆叠
│   └── loot.ts            战利品生成/掉落表/尸体掉落/空投
├── zone/zone.ts           七阶段安全区与圈外伤害
├── ui/
│   ├── hud.ts             HUD：血条/武器卡/小地图/击杀流/横幅
│   └── inventoryUI.ts     背包面板
└── utils/                 数学与随机数工具
```
