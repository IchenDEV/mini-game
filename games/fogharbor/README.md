# Fogharbor · 河岸与上城

盐锈巷、第七码头和老泵站组成一片连续的维多利亚蒸汽河岸。沿街走过住户门前，也可以穿过三座石桥，经南岸步道绕回工坊。南岸的石阶通往客栈院、邮局广场和两级教堂庭院，钟匠高街升至河岸上方 5.4 米。进入泵站后屋顶逐渐隐去，室内外处于同一个三维世界。

高架铁路上运行着深绿黄铜蒸汽机车与木饰客车，车轮、连杆和排汽随行驶联动。铆接钢梁承托连续弯道，帆布飞艇在屋顶上方缓慢巡航。合集包含三类交通所需的浏览器模型与贴图。

河道使用带动态水纹的反射材质，桥拱与煤气灯映在水中。三座石桥具备连续拱腹、楔形拱石和铁艺栏杆；河岸及台地挡土墙采用凿面石块、压顶、扶壁、排水口与潮痕。悬铃木和鹅耳枥带有分枝、树皮与轻微风动，墙脚分布湿土、短草和灌丛。雨后的约克石板保留干湿交错的表面与不规则浅积水。

码头泊着两艘小货船，搬运工沿街送货；客栈后院有人收拾晾衣绳，教堂西侧有人照料育苗台。帆布、衣物和船身随风水轻动。靠近面包车、货船、晾衣绳与育苗台，可以听到诺拉的几句观察。这些日常片段不改变主线进度。

## 十处新街坊

河岸向上城延伸出十处连续街坊，新增 30 栋独立设计的建筑。街道在 0、2.7、5.4、8.1 米的台地之间折转；坡道、石阶和院落连接上下城，低街另有连续的马车道。

| 街坊 | 可进入的建筑 |
| --- | --- |
| 圣烛教堂山院 | 新教堂、牧师宅、唱诗学校 |
| 河湾医院 | 医院、药房、洗消房 |
| 铜鹿酒馆街 | 酒馆、酿酒屋、小剧场 |
| 铁穹市场 | 市场大厅、面包房、鱼铺 |
| 驿马车站院 | 马车站、马厩、车轮修理铺 |
| 旧城清运巷 | 清运站、回收铺、公共洗衣房 |
| 印刷邮务街 | 邮务分拣所、印刷厂、装订书店 |
| 铜机学徒院 | 仪器工坊、钟表铺、学徒宿舍 |
| 闸口货栈 | 保税仓、海关所、船具行 |
| 城墙温室院 | 温室、气象观测所、花匠住宅 |

三十栋均开放有用途的首层。十处主要室内包含不同的工作、等候或陈列区域；走过真实门洞时屋顶和迎镜墙退隐，离开后恢复。室内有干燥木地板、专属家具和局部灯光，不开放全部楼层。

新增二十名街坊、客运与货运两辆马车、五只猫和五只狗。两处停靠点有候车人和搬运工；客车开门、上下客后继续行驶，货车完成包裹装卸，遇到玩家阻挡时等待。猫会理毛、蜷卧、伸展和跳上院里的长椅；狗会嗅闻、停坐，部分会跟随近处的诺拉。院后区分花圃、墓碑、煤灰箱和货物堆放处，排汽来自建筑实际管口。

## 游玩

启动项目后在桌面浏览器游玩，或托管构建生成的 `dist/`。

- 点击地面 / WASD / 方向键：沿可达道路移动。
- 拖拽 / 滚轮：旋转、缩放镜头；镜头延迟跟随角色。
- E：与附近人物或物件互动。
- M：打开城区图，点选地点后角色步行前往。
- J：维修簿；R：恢复视角。
- 高楼挡住诺拉时，会显示淡金色轮廓，帮助跟随她的位置。

旧版存档会保留茶炉维修、交期安排和信件进度。完成原第一章的玩家可以直接沿河前往码头。途中位置也会自动保存。设置里可以重看开场，或重新开始整段河岸故事。

## 一段连续的故事

工坊检查茶炉 → 给街坊安排交期 → 送回莫莉的汤铺 → 比较共同异响 → 收到旧地址的信 → 和米洛沿河步行 → 查看码头住户门前的积水 → 找贝克 → 进入泵站检查供汽 → 只修外侧阀盖 → 确认排水恢复 → 自选路线返回汤铺。

途中没有章节完成页、传送或场景加载页。修复后，泵站恢复连续运转，住户门前的积水退成湿痕，盐锈巷的设备也不再间歇停顿。米洛会同行，贝克留在泵站，莫莉继续照看汤铺。完成交代后仍可自由走访。

主线仍是原有三片城区的河岸故事。新增十个街坊提供工作日常和可观察的室内片段，场景线见 [SCENES.md](SCENES.md)；这些片段不改写主线进度，也不等于十二章全作已经完成。

## 开发与素材

```sh
npm ci
npm run dev -- --port 5188
npm test
npm run build
```

使用 Three.js 与 Vite。建筑、角色与头像为本项目重新制作，未抽取参考 demo 的素材。部分表面贴图与音效使用外部素材，来源见 `public/textures/CREDITS.md` 和 `public/theatre/CREDITS.md`。本合集保留运行所需的导出模型、贴图、源码与 LOD 清单；沿岸六种建筑以实例化组合成 63 座楼房。北岸围绕铁路后的装卸院、住屋街坊和工坊后巷围合；南岸由 2.7 米高街串联客栈后街，邮局前庭位于 1.2 米台地，教堂上庭抬至 4.2 米。六段石阶与两条坡巷连通这些地点，可以从院后一路走到教堂。城区图直接使用同一份布局数据。地形、楼梯、建筑落点与导航约束统一记录在 `src/terrain.js`；三片城区共用相同的砖石、瓦、木与黄铜材质标准。

河阶里从南岸步道直接登阶进入，窄巷从两栋住屋之间穿过；钟匠高街位于原高街之上，可经 18 级石阶上行。建筑的凸窗、铁艺阳台和蒸汽立管使用独立模型，北岸另有两条连接楼层的封闭服务连廊。城区图可直接选择这两处新地点。

访问 `/?model=1&overview=1` 可查看全城俯瞰。`/?model=1&district=scene03` 直接从铜鹿酒馆街的建模入口开始；`scene01` 至 `scene10` 对应上表顺序。正常游戏通过城区图步行抵达各地。

扩建的建筑落点、道路、花圃与门洞共用 `src/expansion-layout.js`；室外铺地按路面并集生成，楼梯踏面与行走高度一致。模型的三档运行时几何与来源校验记录在 `models/lod-manifest.json`。

访问 `/?model=1` 可直接查看盐锈巷的建模版本；此入口使用独立存档，每次刷新从检查茶炉前开始。常规入口保留故事开场与原存档。

在合集内，构建生成标准 Vite 静态产物并发布到 `games/fogharbor/`。建议通过本地 HTTP 服务打开；本地 `file://` 直开未验证。实际帧率取决于硬件和浏览器，画质会按负载调整内部渲染分辨率。

远景细节优化默认开启，可在“设置与操作”中切换。建筑、树木、城墙、码头、泵站与铁路附件根据镜头距离及缩放使用三档几何精度；人物附近和进入的房间保留原始细节，远处模型保持原有材质与轮廓。
