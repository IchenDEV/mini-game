# Architectural surface materials

Roof Slates 03 — Rob Tuytel / Poly Haven.
https://polyhaven.com/a/roof_slates_03
License: CC0.

Included: 1K diffuse, OpenGL normal and roughness JPGs. The original asset covers 3 metres; the authored roof mesh uses physical-scale UVs. No displacement changes the building silhouette.

The limestone.png surface pre-existed this architectural revision.


Large Grey Tiles — Rob Tuytel / Poly Haven.
https://polyhaven.com/a/large_grey_tiles
License: CC0.

Included: 1K diffuse, OpenGL normal and roughness JPGs for the wet street paving. Physical coverage is 3 metres. The workshop and soup house GLBs embed Roof Slates 03 and the existing limestone surface; their meshes were authored for Fogharbor in Blender.


Brick Wall 001 — Dimitrios Savva (photography), Rob Tuytel (processing) / Poly Haven.
https://polyhaven.com/a/brick_wall_001
License: CC0.

Included: 1K diffuse, OpenGL normal and roughness maps for the authored brickwork; also packed into building GLBs.


Wood Table Worn — Dimitrios Savva (photography), Rico Cilliers (processing) / Poly Haven.
https://polyhaven.com/a/wood_table_worn
License: CC0.

Included: 1K diffuse, OpenGL normal and roughness maps, packed into authored building assets for counters, doors and workshop furniture.
