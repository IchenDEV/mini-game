# 六城之心 · The Six Hearts

一个明亮白昼里的蒸汽朋克探索小游戏。六座城的动力网络沉寂了，你需要找回动力组件、修复核心，乘飞艇点亮整条航线。

## 六段旅程

黄铜港 → 翡翠温室 → 潮汐水厂 → 余烬铸造厂 → 星环天文台 → 云海总站。

每座城市都有独立建筑、动态机械与音乐编排。寻找三枚区域动力组件，按机械铭牌的提示依次启动三个控制器，再到航站启航。输错顺序可以重试，不会丢失组件。六座核心全部恢复后，可以通过航线图自由往返。

旅程进度自动保存在当前浏览器中；再次打开游戏选择“继续旅程”即可。不同浏览器或不同网址的存档彼此独立。

## 运行

先运行 `npm ci` 和 `npm run build`，再用浏览器打开生成的 **Brasshaven.html** 即可运行离线演示，无需启动服务器。直接打开 `index.html` 也会进入该离线版。

修改源码时使用开发服务器：

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。

## 操作

| 操作             | 效果                                   |
| ---------------- | -------------------------------------- |
| 点击地面         | 机械师走向目标，活动范围限定在码头广场 |
| 拖拽             | 环绕旋转视角                           |
| 滚轮             | 拉近或拉远                             |
| 方向键           | 移动角色                               |
| A / D            | 旋转视角                               |
| + / −            | 缩放                                   |
| R                | 返回起始位置和视角                     |
| F                | 切换全屏                               |
| E                | 与附近的组件、控制器或航站互动         |
| Tab / 航线图按钮 | 打开六城航线图                         |
| M / 音乐按钮     | 开启或关闭背景音乐                     |
| 音量滑块         | 调整音乐与反馈音量                     |

点击道具实体或小型标记，会自动走近并互动。悬停或走近时显示名称，避免标签遮挡建筑。六城分别收集传动齿轮、生命种芯、水轮叶芯、耐热炉芯、星象透镜和点火线圈。点击“开始旅程”后启用背景音乐。原创音乐盒主题贯穿六城，配有六种区域编排、柔和伴奏与收集、修复反馈音效，全部由 Web Audio 在本地合成。切到后台时暂停声音，返回后恢复。

## 静态构建

```sh
npm run build
npm run preview
```

构建同时更新离线版 `Brasshaven.html`。`dist/` 可由任意静态服务器托管。运行时所有资源均来自本项目，无外部字体、贴图、模型或音频请求。

建筑和材质由项目代码生成。机械师由本项目的 Blender 脚本建模，可用以下命令重新生成：

```sh
blender --background --python scripts/build-character.py
```

帧率显示为当前浏览器实际帧率，受设备性能、分辨率和屏幕刷新率影响；渲染分辨率会在持续低帧率时自动调整。
