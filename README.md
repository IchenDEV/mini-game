# 松果小市

一款可直接在浏览器游玩的像素风超市模拟经营小游戏。玩家需要在三天内完成进货、补货、升级和收银，兼顾现金流、货架库存、顾客耐心与商店口碑。

## 运行

需要 Node.js 20+ 与 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址即可开始游戏。

```bash
pnpm test
pnpm typecheck
pnpm build
```

## 玩法

- 「进货」把商品采购到仓库。
- 「补货」把仓库商品摆到货架。
- 「升级」提升货架容量、顾客耐心或收银效率。
- 点击场景左下角收银台，或按空格键，为队首顾客结账。
- 完成三天营业后，根据累计营业额、利润、口碑与顾客服务情况结算成绩。

快捷键：

- `Space`：为队首顾客结账
- `1` / `2` / `3`：切换进货、补货、升级面板
- `P`：暂停或继续营业

游戏进度会自动保存在当前浏览器的 `localStorage` 中，可在设置里清除并重新开店。

## 技术结构

- React + TypeScript：HUD、经营面板、教程和结算界面
- Phaser：超市场景、动物顾客、排队与反馈动画
- Vitest：经营规则、三日流程和存档校验
- Vite：开发与生产构建

像素场景、动物顾客和商品图集均为本项目原创生成素材，界面文本与交互控件由代码绘制。
