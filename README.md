# 海风渔港

一款可直接在浏览器游玩的手绘卡通钓鱼模拟经营游戏。玩家需要掌握甩竿与张力收线，把渔获立即卖给码头，或存入冷藏箱完成高价订单，再用收益升级装备、解锁钓点和补全海洋图鉴。

## 运行

需要 Node.js 24+ 与 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址即可开始游戏。

```bash
pnpm test
pnpm typecheck
pnpm build
```

## 玩法

- 选择鱼饵，按住「甩竿」或空格蓄力，松开抛出鱼线。
- 浮标出现叹号时立即扬竿。
- 收线时按住提高张力、松开降低张力，让指针留在绿色安全区。
- 捕获后可立即出售，或存入有限的冷藏箱以完成高倍率港口订单。
- 使用贝壳币升级鱼竿、卷线器、冷藏箱和渔船。
- 渔船升级后可前往珊瑚礁与月光深海，收集更稀有的鱼种。
- 每天有固定出竿次数，天气与订单会在次日刷新。

快捷操作：

- `Space`：按住甩竿 / 扬竿 / 按住收线
- 点击水面：使用固定力度快速执行当前钓鱼动作

经营进度、图鉴纪录和装备升级会自动保存在当前浏览器的 `localStorage` 中，可在设置里清除。

## 技术结构

- React + TypeScript：HUD、订单、工坊、鱼舱、图鉴、教程与日结
- Phaser：海湾场景、甩竿曲线、浮标、水花、鱼影和捕获反馈
- Vitest：钓鱼状态机、订单、升级、跨天流程与存档校验
- Vite：开发与生产构建

海湾、角色与六种鱼类图集均为本项目原创生成素材。界面文字、经营数据和所有可交互控件由代码实现。
