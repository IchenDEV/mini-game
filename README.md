# 星轨织者

一款围绕引力与切线飞行设计的单键动作游戏。按住鼠标、触屏或空格，星针会牵引最近的锚星；松开后沿切线发射。依次抵达目标星、擦过蚀洞并收集火花，在夜色耗尽前缝出尽可能长的星轨。

在线游玩：https://ichendev.github.io/mini-game/

## 运行

需要 Node.js 24+ 与 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址即可开始游戏。

```bash
pnpm test
pnpm typecheck
pnpm build
```

## 操作

- 鼠标 / 触屏 / `Space`：按住牵引，松开发射
- `P`：暂停或继续
- `M`：开启或关闭声音
- `R`：重新开始

每局初始 75 秒。缝合目标星会提高连击、得分并补回少量时间；靠近蚀洞但不相撞可获得险距奖励；碰撞蚀洞会扣时并中断连击。最高分保存在当前浏览器中。

## 技术结构

- React + TypeScript：HUD、开局、暂停与结算状态
- Phaser：引力运动、碰撞、锈红轨迹、粒子和输入
- Web Audio：程序化牵引、发射、缝合、险距与碰撞音效
- Vitest：计时、几何、目标选择、奖励和最高分契约
- Vite：开发与生产构建

`?qa=1` 会启用固定随机种子，便于重复浏览器验收。生成的游戏概念、夜空背景和可碰撞图集位于 `public/assets/`；HUD 文字、物理与碰撞均由代码实现。
